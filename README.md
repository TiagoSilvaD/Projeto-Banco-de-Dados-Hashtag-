# 📊 Projeto de Banco de Dados — Hashtag

Projeto desenvolvido para análise de cancelamentos e identificação de possíveis
causas relacionadas à perda de clientes e vendas.

## 🎯 Objetivo

Analisar os dados de cancelamentos para identificar padrões e informações
que possam ajudar na tomada de decisões e na redução da perda de clientes.

## 📁 Arquivos

- `inicial.ipynb` — análise inicial dos dados
- `gabarito.ipynb` — resolução/análise final
- `cancelamentos.csv` — base de dados utilizada no projeto

## 🛠️ Tecnologias

- Python
- Pandas
- Jupyter Notebook
- Análise de Dados

## 📈 Principais análises

- Taxa de cancelamento
- Perfil dos clientes que cancelaram
- Identificação de padrões de cancelamento
- Análise das possíveis causas de perda de clientes
